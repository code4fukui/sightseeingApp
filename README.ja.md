# 福井県観光アンケートコメントマップ (sightseeingApp)

福井県の観光アンケートのコメントを可視化するインタラクティブな地図アプリケーションです。このツールは、訪問者のフィードバックを満足度別に色分けして地図上にプロットし、各エリアにおける観光体験の傾向を把握しやすくします。

**ライブデモ: [https://code4fukui.github.io/sightseeingApp/](https://code4fukui.github.io/sightseeingApp/)**

## 機能

- **インタラクティブな地図:** 福井県の地図上にアンケート回答をポイントとして可視化します。
- **満足度の色分け:** マーカーは報告された満足度に応じて色分けされています:
  - 🔵 **青:** 満足 / とても満足
  - 🟡 **黄:** どちらでもない
  - 🔴 **赤:** 不満 / とても不満
- **詳細なポップアップ:** 任意のマーカーをクリックすると、回答日時、訪問者の属性、満足度の理由、交通や施設に関するコメントなど、アンケートの回答全体を表示できます。
- **エリアセレクター:** ドロップダウンメニューを使用して、特定の観光エリアに素早くズームできます。
- **動的フィルタリング:** チェックボックスを使用して、満足度別にマーカーの表示/非表示を切り替えることができます。
- **マーカー位置の分散（ジッター処理）:** マーカーの位置は指定されたエリア内でわずかに分散され、重なりを防いで視認性を向上させています。

## 使い方

これはブラウザ上で完全に動作する静的なWebアプリケーションです。ビルドプロセスやサーバーは必要ありません。

1. リポジトリをクローンします。
2. `index.html` ファイルをWebブラウザで開きます。

## データソースとクレジット

このアプリケーションはオープンデータを活用しています。

- **主なデータソース:** [福井県観光アンケートオープンデータ (Fukui Tourism Survey Open Data)](https://github.com/code4fukui/fukui-kanko-survey/)
- **アイコンクレジット:** [マーカー icon by Icons8](https://icons8.com/icon/OBmVbH2qOGwK/%E3%83%9E%E3%83%BC%E3%82%AB%E3%83%BC)
- このプロジェクトは [福井県観光データ分析システム「FTAS (FUKUI Tourism data Analizing System)」](https://www.fuku-e.com/feature/detail_266.html) に関連しています。

## 技術スタック

このアプリケーションは、ピュアなHTML、CSS、JavaScript (ESモジュール) で構築されており、以下のライブラリをCDN経由で利用しています。

- [OpenLayers](https://openlayers.org/): インタラクティブな地図の描画。
- [OLMap.js](https://github.com/eiichimiyagawa/OLMap): OpenLayersの利用を簡略化するラッパーライブラリ。
- [CSV.js](https://github.com/code4fukui/js.sabae.cc): ソースから取得したCSVデータを解析する軽量ライブラリ。
